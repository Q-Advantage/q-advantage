# Q-Advantage

> Open benchmarks and intelligence layer for the quantum era.

Q-Advantage publishes reproducible, auditable benchmarks for post-quantum cryptography and quantum hardware. Every result is generated by public code on dedicated hardware, committed automatically, and traceable to a methodology you can read.

## Surfaces

- **Q-Shield** — Post-quantum cryptography benchmark dashboard. ML-KEM, ML-DSA, SLH-DSA latency, throughput, and key/signature sizes measured weekly.
- **Q-Arena** — Algorithm benchmarks (Shor's, Grover's, VQE) on quantum simulators and, where available, real hardware.
- **Q-Day Index** — A single number tracking how close current quantum hardware is to breaking widely-deployed cryptography.

## How it works 
No hidden infrastructure. No marketing-grade numbers. The recipe is in `/benchmark`, the methodology is in `METHODOLOGY.md`, and every weekly run is one click away in the Actions tab.
